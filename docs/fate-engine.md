# 命局与行运推演引擎

## 目的

本引擎用于把排盘后的阅读从固定的反思提示，改为一条可检查的传统八字推演链条。它不把单一十神或单一大运直接等同于某个必然事件；每个结论都必须同时显示其命局依据与行运条件。

## 处理顺序

| 步骤 | 引擎动作 | 输出给用户的依据 |
|---|---|---|
| 月令 | 读取月支主气，并换算为相对于日主的十神 | 月令、主气、十神 |
| 日主旺衰 | 对天干、藏干、月令加权，比较生扶与泄耗克制，并统计通根 | 日主强弱、根气、相对分量 |
| 取用倾向 | 在扶抑基础上识别寒暖燥湿的调候需要，得出当前优先与偏忌的五行 | 扶抑/调候、喜用倾向 |
| 命局关系 | 检查天干五合、地支六合、六冲、六害、子卯刑、三刑及三合/三会 | 合、冲、害、刑、会局 |
| 行运 | 将当前大运干支映射为十神与五行，再与喜忌和原局关系并看 | 大运、运干十神、运支关系 |
| 流月 | 按年干起寅月干，生成所选农历月干支，与命局及大运同看 | 流月干支、命局落点、行运关系 |

传统子平框架强调先以月令配合四柱，再讨论日主强弱、用神及行运；《子平真诠评注》亦明确将扶抑、病药、调候、专旺与通关列为取用的不同路径。[1] 该资料同时指出，同一十神需依月令与全局配合判断，不能仅凭“见财”“见官”直接推定结果。[2]

> “用神专求月令，以日元配月令地支，察其旺衰强弱而定用神也。”[2]

## 规则化范围

本版本将上述传统路径实现为**可复现的规则化近似**，适合产品中的基础阅读和依据展示。它不会宣称穷尽格局成败、从格、神煞、宫位、流派差异或人工师承判断。对合化，界面明确显示“是否化气仍看月令与根气”，不将五合自动视为化局。

| 内容区 | 呈现方式 | 禁止的写法 |
|---|---|---|
| 事业与职分 | 官杀位置、月令、日主承载力与大运条件 | “必升职”“必失业” |
| 财运与财星 | 财星位置、身强弱、比劫/食伤/官杀配合与大运条件 | “必发财”“应买卖/借贷” |
| 关系与婚姻 | 配偶星、日支关系与大运条件 | “必结婚”“婚姻已定” |
| 流月 | 流月干支与命局、大运的关系 | “某月必发生某事” |
